# medium-connect-elements-with-css-part2

Repository used to illustrate [the Medium article](https://medium.com/@rochejul/connect-html-elements-with-only-css-part-2-automatically-position-with-only-css-21152c1c5998) to illustrate how to connect elements with CSS. This project shows the CSS allowing to adapt the link position/style depending of the box elements positions.

Please use the [live demo](https://rochejul.github.io/medium-connect-elements-with-css-part2/).
